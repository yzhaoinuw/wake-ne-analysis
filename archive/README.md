# Historical material

This directory preserves superseded analyses and presentation artifacts without
placing them on the current PI-facing path.

- `writeups/` and `assets/` are earlier reports and their figures.
- `legacy_pipeline/` is the original generic manifest-based NE workflow, including
  its examples, scripts, package snapshot, and tests.

The maintained workflows are documented in the repository root and implemented in
`scripts/` and `wake_ne_analysis/`. Historical material is retained for provenance,
not as a recommendation for new analysis.
